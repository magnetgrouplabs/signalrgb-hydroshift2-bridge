# Lian Li HydroShift II for SignalRGB (retired 2026-09-01)

This add-on currently ships NO plugin. The HydroShift II LCD-S 360 is driven entirely by the
FanControl.HydroShift2 plugin (private HydroShift2 repository): pump curve, a GIF or still image on
the 480 x 480 panel from the plugin's own renderer, and a fixed colour on the 24-LED ring. The
device is single-owner WinUSB, so SignalRGB must not hold it while FanControl does. The SignalRGB
plugins that lived here (bridge 0.2.1 to 0.4.0, direct plugin 1.0.0 to 1.1.0) remain in the git
history and in the HydroShift2 repository.
